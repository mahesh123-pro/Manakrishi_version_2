# Editorial website images

- `field-drone-editorial.webp`: AI-generated photorealistic agricultural drone scene.
- `farmer-advisor-editorial.webp`: AI-generated photorealistic farmer and crop advisor scene.
- `home-drone-flight.webp`: AI-generated drone flight scene for the homepage media feature.
- `home-drone-operator.webp`: AI-generated operator pre-flight scene for the homepage gallery and About section.
- `farmer-family-insurance.webp`: AI-generated photorealistic farming family discussing insurance with an advisor.
- `farmer-scheme-assistance.webp`: AI-generated photorealistic farmer receiving scheme application assistance.

The full prompts for the support-card replacements are in `support-image-prompts.md`; both were created with the built-in image-generation tool.

New homepage prompts are in `homepage-image-prompts.md`. The homepage MP4 is an animated photo montage; see `../videos/README.md` for its source images and rebuild instructions.

Created for Manakrishi's marketing design. These are illustrative visuals, not photographs documenting actual customers, staff, or service jobs. Original files are retained in the Codex generated-images folder; the site uses compressed WebP versions with responsive Next.js image delivery.
