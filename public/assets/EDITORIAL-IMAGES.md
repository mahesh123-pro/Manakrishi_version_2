# Editorial website images

- `field-drone-editorial.webp`: AI-generated photorealistic agricultural drone scene.
- `farmer-advisor-editorial.webp`: AI-generated photorealistic farmer and crop advisor scene.

Created for Manakrishi's marketing design. These are illustrative visuals, not photographs documenting actual customers, staff, or service jobs. Original files are retained in the Codex generated-images folder; the site uses compressed WebP versions with responsive Next.js image delivery.
